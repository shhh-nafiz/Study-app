StudyLock - minimal study timer that blocks apps

GET THE APK (no coding), easiest way:
1. Make a free account at github.com and create a new repository (name: StudyLock).
2. Upload ALL files from this folder to it (drag the contents in). Make sure the
   hidden folder .github/workflows/build.yml is included. If it's missing, click
   Add file > Create new file, name it  .github/workflows/build.yml  and paste the
   contents of that file.
3. Open the Actions tab, wait ~3-5 minutes for "Build APK" to turn green.
4. Click the run > scroll to Artifacts > download StudyLock-apk, unzip it, and
   you get app-debug.apk. Copy it to your phone and install it.

OR: install Android Studio, open this folder, press Run (or Build > Build APK).

WHAT'S NEW IN 1.1
- Timer no longer runs past zero; it now ends exactly on time even with the screen off.
- Alarm rings (alarm volume + vibration) when the timer finishes. Tap "Stop alarm".
- Pick the time like an alarm clock: spin the hours and minutes wheels (1-minute steps).
- Study log shows dated sessions and a 7-day / 30-day bar chart.

NOTE: if installing over your old version fails ("App not installed"), uninstall the old
one first (the old study log will be reset), then install the new APK.

WHAT'S NEW IN 1.3
- Settings: accent colour, background colour (incl. a light "Paper" theme), alarm sound
  (pick any alarm tone or silent), vibration on/off, ring length, test button.
- Daily goal with a thin progress bar and streak; one quiet line of text on the home screen
  (can be switched off). Dashed goal line on the log chart.
- Share this week: sends your weekly total as text to any app/friend.
- Log entries and whole days can be deleted.
