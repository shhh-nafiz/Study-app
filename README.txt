StudyLock - minimal study timer that blocks apps

GET THE APK (no coding), easiest way:
1. Make a free account at github.com and create a new repository (name: StudyLock).
2. Upload ALL files from this folder to it (drag the contents in). Make sure the
   hidden folder .github/workflows/build.yml is included. If it's missing, click
   Add file > Create new file, name it  .github/workflows/build.yml  and paste the
   contents of that file.
3. Open the Actions tab, wait ~3-5 minutes for "Build APK" to turn green.
4. Click the run > scroll to Artifacts > download StudyLock-apk, unzip it, and
   you get app-debug.apk. Copy it to your phone and install it.

OR: install Android Studio, open this folder, press Run (or Build > Build APK).
